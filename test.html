<tidbit-carousel> — capability test suite

Each panel below drives a distinct part of the component's surface: layout axes, wrap/no-wrap boundaries, scroll input sources, autoscroll timing and interruption, focus/pause lifecycle, dynamic content mutation, per-item sizing, and justification gating. Numbers shown are live values read straight off the element's public getters.

Hook functions (init_hook, scroll_hook, focus_hook, etc.) can only be supplied through HTML attributes, and attributes can't carry function values — so no external script, including this one, can actually register a hook callback on a declaratively-created instance without editing the component's own source. Section 08 and the shared log below instead reconstruct the same transitions by polling the public getters every frame and diffing them, which observes the identical state changes the hooks would fire on — logged with a * suffix to mark them as inferred rather than hook-invoked.
